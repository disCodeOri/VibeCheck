# vibecheck. — Desktop male v1

Six desktop concept screens generated with the built-in imagegen tool, using the latest male mobile design as the visual reference. These are static PNG mockups, not an interactive application. Scores, sample identity, photo metadata and feedback are illustrative.

## Screens

1. `01-home.png` — Cutout hero over oversized type, adjacent upload panel and feature shortcuts.
2. `02-story-result.png` — Photo alongside a notched score ticket and actionable feedback.
3. `03-compare.png` — Two-photo workspace with comparison metrics and style references.
4. `04-loox.png` — Photo callouts alongside hairstyle previews and style-match feedback.
5. `05-wardrobe.png` — Searchable/filterable garment grid concept with model setup panel.
6. `06-chicfit.png` — Large 3D preview concept with alternate views, rotation cue, garment controls and score ticket.

The shared sidebar, navy/cobalt palette, clean typography and crisp overlapping blue plates carry the male direction to desktop. Original brand source files should be used for implementation rather than extracting generated logos. The mockups represent controls and 3D interactions visually only.
