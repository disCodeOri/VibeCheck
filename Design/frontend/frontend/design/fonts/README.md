# Vibe Check Fonts

This design system uses 3 complementary font families:

1. **Anton** (`Anton_400Regular`)
   - High-impact condensed geometric sans.
   - Used for the primary app headline: `ONE VIBE.\nALL YOU.`

2. **Instrument Serif** (`InstrumentSerif_400Regular` & `InstrumentSerif_400Regular_Italic`)
   - Editorial, expressive fashion serif.
   - Used for hero statement headings (e.g. *"Your Story. Your Way."*, *"Your Mood. Your Version."*).

3. **DM Sans** (`DMSans_400Regular`, `DMSans_500Medium`, `DMSans_700Bold`)
   - Neutral, ultra-legible modern grotesk.
   - Used for all UI body text, buttons, scorecard metrics, chips, and navigation labels.

### Installation

```bash
npx expo install @expo-google-fonts/anton @expo-google-fonts/instrument-serif @expo-google-fonts/dm-sans expo-font
```
